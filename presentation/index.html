ARCHITECTURE

화면 두 개, 상태는 하나

호스트

아이패드 · 진행자
슬라이드, 버저, 판정 조작

서버

Node · Express · Socket.io
방 상태의 유일한 기준

뷰어

노트북 + 프로젝터
슬라이드 표시, 키보드 버저

goToSlide · setBuzzer · judge buzz { key: "Q" } roomState → 모든 화면에 방송

버튼을 누르면 서버가 상태를 바꾸고, 같은 방의 모든 화면이 즉시 같은 화면으로 바뀝니다.

HOW IT RUNS

퀴즈 한 판의 진행 순서

1
방 만들기

호스트가 방을 만들면 방 코드가 생겨요.

2
뷰어 접속

방 코드 입력 또는 뷰어 링크 복사로 노트북을 연결해요.

3
슬라이드 업로드

PPT를 PNG/JPG로 내보내 여러 장 올려요.

4
참가자 설정

2~8명, 이름과 키를 정하고 중복 키는 막아요.

5
버저 활성화

문제 슬라이드에서 원하는 순간 버저를 열어요.

6
키 누르기

참가자가 자기 키를 누르면 순위가 기록돼요.

7
정답 · 오답 판정

정답 +1, 오답 −1 후 다음 순위에게 답변권.

8
퀴즈 종료

최종 순위와 시상식 화면이 펼쳐져요.

9
처음으로

같은 방, 같은 슬라이드로 점수만 초기화해요.
